Music Spectrum Lyrics Studio - Asset Placeholders
===================================================

This folder contains placeholder files for the application assets.

Directory Structure:
- icons/     - Application icons (SVG, PNG, ICO)
- fonts/     - Custom fonts (TTF, OTF)
- cta/       - CTA animation templates (GIF, WEBM, MP4)
- logos/      - Sample logos for testing
- samples/   - Sample audio/video files
- placeholders/ - This folder with placeholder documentation

To customize:
1. Place your own fonts in assets/fonts/
2. Place CTA animations in assets/cta/
3. Place logos in assets/logos/
4. The application will use system fonts if no custom fonts are found.
